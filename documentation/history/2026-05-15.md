## Follow-up fixes on `main`

- **`String.replace` `$`-pattern corruption** in `TranscriptionService.ensureFrontmatterTags`. The three replacement spots passed plain strings as the replacement argument, so a `$` in a tag value (e.g. `my$&tag`) would be expanded as a regex back-reference and silently corrupt the frontmatter. Switched all three to the function form (`replace(pattern, () => replacement)` / `replace(/^(tags:\s*\n)/m, (_match, p1) => `${p1}${insertion}\n`)`).
- **Test coverage** for `ensureFrontmatterTags`. Added five cases in `src/app/services/transcription-service.spec.ts` covering: no frontmatter, frontmatter without `tags:`, partial-merge into existing `tags:`, idempotent no-op when all tags present, and the `$`-safety regression.
- **Business rule** for Frontmatter Tags added to `documentation/Business Rules.md`.
